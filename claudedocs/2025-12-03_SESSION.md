- Tests: Timing out waiting for `/explore/{id}` URL pattern

**Possible Root Causes**:
1. **Workflow Context Blocking**:
   - `canAccessStage(WorkflowStage.DATA_PROFILING)` check in explore page (line 49-52)
   - May be redirecting back to upload before tests can detect navigation

2. **Router Not Initialized**:
   - Next.js router may not be ready in test environment
   - `router.push()` calls silently failing

3. **State Batching Issue**:
   - React batching state updates
   - `uploadedFileId` state not set before `router.push()` executes

4. **Navigation Race Condition**:
   - Multiple navigation triggers competing
   - useEffect and direct calls interfering with each other

5. **Test Environment Issue**:
   - Playwright not detecting client-side navigation
   - Need different wait strategy than `waitForURL()`
