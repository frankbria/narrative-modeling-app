# 🧠 Narrative Modeling App: User Functionality Guide

## 🎯 What is the Narrative Modeling App?

The Narrative Modeling App is an AI-guided platform that empowers non-expert analysts, business professionals, and domain experts to build, explore, and deploy machine learning models without writing code. It combines powerful automation with an intuitive, story-driven workflow to make machine learning accessible to everyone.

## 🚀 Key Capabilities: What You Can Do

### 1. 📊 Data Loading & Management

**What's Possible:**
- **Drag-and-drop file uploads**: Easily upload CSV, Excel (XLS/XLSX), TXT, and JSON files
- **Large file support**: Handle files up to 100MB+ with chunked upload technology
- **Automatic data scanning**: Instant schema detection and preview
- **PII (Personally Identifiable Information) detection**: Automatic identification of sensitive data with risk assessment
- **Data masking options**: Choose to mask sensitive information or keep original data
- **Cloud storage integration**: Files are securely stored in AWS S3

**How It Works:**
1. Drag your data file into the upload zone or click to browse
2. The system automatically detects file type and structure
3. For large files (>50MB), chunked upload ensures reliability
4. PII scanner analyzes your data for sensitive information
5. If PII is detected, you choose how to handle it (mask or keep)
6. Data is securely uploaded and stored in the cloud

**User Benefits:**
- No technical setup required
- Immediate feedback on data quality
- Built-in privacy and compliance features
- Support for common business data formats
