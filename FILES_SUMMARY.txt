API INTEGRATION
================================================================================

Endpoints Used:
  GET /api/v1/user_data/{datasetId}
    Headers: Authorization: Bearer {token}
    Response: { id, filename, num_rows, num_columns, schema?, file_id? }

  POST /api/v1/transformations/apply (via TransformationPipeline)
    Body: { dataset_id, transformations }
    Response: { transformed_dataset_id, row_count, schema }

Authentication:
  - All API calls use getAuthToken() for bearer token injection
  - Token management via NextAuth session
  - Automatic refresh handled by session middleware
